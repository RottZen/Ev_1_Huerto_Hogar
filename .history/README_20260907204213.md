##Descripción del proyecto
**HuertoHogar** es una plataforma orientada a la comercializacion de productos agricolas y orgánicos directo al consumidor. El sistema incluye una experiencia pública para clientes con catalogo dinámico y carrito de compras, junto con un panel de administración para la gestion de inventario y usuarios.
